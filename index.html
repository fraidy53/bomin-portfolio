GameOps Analytics

Go API → Kafka → Python Consumer → PostgreSQL로 가상 게임 이벤트를 수집·집계하는 개인 프로젝트.

설계와 검증 범위

DB 저장 후 offset을 commit하고, event_id와 ON CONFLICT로 중복 저장을 방지하는 구조입니다. DAU·리텐션·매출 지표를 SQL View로 정의했습니다.

가상 데이터 기반입니다. 테스트 가이드와 구현 코드를 구분하며, AWS 구성은 실제 배포가 아닌 확장 설계입니다.

지역 경제 뉴스 모니터링

뉴스 크롤링·데이터 정리와 기간·지역별 집계를 Folium 지도 시각화로 연결했습니다.

집계와 해석 범위

UNION ALL로 뉴스 DB를 결합하고, 기간 조건·GROUP BY로 지역별 기사 수와 감성 분포를 집계했습니다.

수집 매체와 기간에 영향을 받는 기사 표본이며, 지역 경제의 실제 위험을 입증하는 지표는 아닙니다.
